# 🚀 Kodie Workshop Project

Aplicação web moderna desenvolvida com foco em performance, escalabilidade e experiência do usuário, utilizando tecnologias atuais do ecossistema JavaScript/TypeScript.

## 📖 Sobre o Projeto

O Kodie Workshop Project é uma aplicação full-stack construída com arquitetura moderna, separando claramente as camadas de frontend, backend e recursos compartilhados.

O projeto foi desenvolvido utilizando Builder.io como plataforma de aceleração de desenvolvimento, com deploy realizado na Netlify.

## 🌐 Demonstração

Acesse a aplicação:

https://incredible-cannoli-79ce4c.netlify.app/

## ⚙️ Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/Ana-Siq/Kodie-Workshop-project.git
```

### 2. Acesse o diretório

```bash
cd Kodie-Workshop-project
```

### 3. Instale as dependências

```bash
npm install
```

ou

```bash
pnpm install
```

---

## ▶️ Executando Localmente

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

ou

```bash
pnpm dev
```

A aplicação ficará disponível em:

```text
http://localhost:5173
```

---

## 📦 Build para Produção

Gerar versão otimizada:

```bash
npm run build
```

ou

```bash
pnpm build
```

---

## 🚀 Deploy

O projeto está configurado para deploy na Netlify.

Para publicar:

```bash
npm run build
```

e realizar o deploy através da plataforma Netlify.
